# 第三方工具来源

Icarus Verilog 是开源仿真器。本机使用 v12 development Windows 发行包，下载地址为 https://bleyer.org/icarus/iverilog-v12-20220611-x64_setup.exe ，安装到本目录的 iverilog 文件夹。原安装器保留在 _history 中。

上游项目与源代码：https://github.com/steveicarus/iverilog 。安装包中附带的 GTKWave 是波形查看器，项目主页：https://gtkwave.sourceforge.net/ 。本项目没有改动这些工具的二进制。

Tang Dynasty 使用用户已安装的软件，没有将 TD 本体或许可复制到交接 ZIP。代码中的安路 IP 保留原始版权与加密内容。
