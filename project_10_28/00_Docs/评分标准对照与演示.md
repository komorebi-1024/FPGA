### SW1和图表的读法

SW1开启时，在区间音乐播放场景启用频谱分析与叠加显示；关闭后面板消失、峰值清空，
音乐本身继续播放。到站暂停音乐时也不显示区间频谱。SW1不负责音量调节。

- `SPECTRUM`：频谱，将音频分解为不同频率成分；不是时间波形。
- `DFT256`：每256个PCM样本计算一次离散傅里叶变换，48kHz下对应约5.33ms音频。
- `LOW`、`HIGH`：从左至右由低频到高频，1～8是八个不等宽频带的编号，不是时间序号。
- 柱越高：该频带相对幅度越强。经过对数压缩、汇总和下降平滑，适合观看音乐变化。
- `REL`：相对幅度，无分贝或声压单位，也不能用八根柱直接判断各频带总功率比例。
- 浅黄色横线：近期峰值。较高输入会更新它；没有新高时保持约0.5秒，再缓慢下降。
- 蓝/青/黄柱体：按显示高度分段着色，用于提高辨识度，不表示危险等级或不同乐器。

频谱取自FPGA内部播放的真实PCM；调小显示器音量不会改变这份PCM，所以柱高也不会随显示器音量变化。
双声道音乐仍按左右声道播放，频谱则分析左右声道平均值。详细频点见下表。

| 柱编号 | DFT bin | 频点覆盖（48kHz/256） |
|---|---|---|
| 1 | 1 | 187.5 Hz |
| 2 | 2～3 | 375～562.5 Hz |
| 3 | 4～7 | 750～1312.5 Hz |
| 4 | 8～15 | 1500～2812.5 Hz |
| 5 | 16～31 | 3000～5812.5 Hz |
| 6 | 32～47 | 6000～8812.5 Hz |
| 7 | 48～79 | 9000～14812.5 Hz |
| 8 | 80～127 | 15000～23812.5 Hz |

使用矩形窗，分辨率187.5Hz，DC与Nyquist未显示；有泄漏，不能宣称能区分63/125Hz低频。
每带对`|I|+|Q|`汇总并近似按bin数归一化后对数压缩，最后48bin用除64近似。
单声道分析取左右声道平均；实际声音仍保持双声道。相位相反的左右声道可能在分析中抵消。

## 建议三分钟演示顺序

1. 接好SD、HDMI，SW2关闭，完全断电后上电：证明不依赖电脑下载启动。
2. 首站等待后展示真实本站语音与三段逐字字幕；语音播完3秒自动离站，展示自动轮播和转场。
3. 区间音乐播放时打开SW1，解释真实DFT、低高频方向及峰值保持。
4. 按KEY3从舒缓钢琴切到轻快器乐，听辨音乐变化并观察谱形差异。
5. 按KEY2到站：提示音后播本站介绍、音乐暂停；播报中按KEY2提前离站，确认音乐续播且无残留语音。
6. 长按KEY3打开设置，演示亮度/对比度数值与照片同步变化，DEFAULT恢复，再长按退出；原字幕/频谱仍可读，长按不切歌。
7. 关闭SW1展示完整景区画面，必要时短暂打开SW2验证独立48kHz测试音，随后关闭。

证据留存：录下断电上电、切歌/频谱、进离站的连续实机录像；仿真PNG必须标“非实机”。
至少跑完整两首到曲尾以验证实际循环，再做约30分钟切图/切歌稳定运行，记录有无断音、花屏或异常菜单。
软件测试不能代替上述硬件长时验收。
