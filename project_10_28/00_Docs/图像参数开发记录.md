## 使用方法

长按板上KEY3约1秒，打开或关闭 `IMAGE SETTINGS` 菜单。
菜单关闭时，KEY2仍负责进离站，KEY3短按仍切换音乐；短按在松开并去抖后确认。
长按只产生菜单事件，松开不会补发切歌。

菜单打开时：

| 项目 | 短按KEY3 | 按KEY2 |
|---|---|---|
| BRIGHTNESS（亮度） | 选择下一项 | 按顺序循环 −64、−32、0、+32、+64 |
| CONTRAST（对比度） | 选择下一项 | 按顺序循环 50%、75%、100%、125%、150% |
| DEFAULT | 选择下一项 | 恢复亮度0、对比度100% |
| EXIT | 回到第一项 | 退出菜单 |

长按KEY3也可退出。菜单内按键不传给站点推进或音乐切换。
语音、音乐、自动离站与区间轮播继续正常运行，设置菜单不暂停它们。
参数在下一帧边界统一生效；退出菜单后保留，按KEY1复位或断电重启回到默认。
SW1频谱、SW2测试音的功能不变。

只调整照片像素，字幕、状态栏、频谱与菜单在之后叠加，便于阅读。
亮度数字是RGB通道数值偏移，不是屏幕背光档位；对比度100%为原始值。
高亮/高对比度时出现饱和裁剪属于预期，DEFAULT可精确恢复原图。

## 实现

`wl_key_gesture`区分短按和长按，`wl_image_ui_ctrl`消费菜单事件并更新9位参数快照：
`{menu_open,selection[1:0],brightness_level[2:0],contrast_level[2:0]}`。
`wl_image_config_source`将最新参数从100MHz控制域送到25MHz像素域，使用request/ack toggle握手，
未收到确认前冻结发送总线；此期间的新按键设置合并为最新状态，确认后再发送。
这也覆盖KEY2/KEY3两个独立事件紧邻发生的情况，不依赖全局按键事件间隔假设。
`wl_image_adjust`同步后再等待VS下降沿锁定整帧配置，避免半帧参数变化。

每个RGB通道的定点运算：

```text
gain_q2 = 2, 3, 4, 5, 6
out = clamp8( (((in - 128) * gain_q2 + 2) >>> 2) + 128 + brightness )
```

中间数有符号，最终饱和到0～255。倍数2～6用移位加法实现，无通用乘法器。
3级像素流水线同时延迟RGB和HS/VS/DE；默认档逐位还原原图。
图像调节放在OSD之前，之后沿用原转场、频谱和音乐菜单，再添加设置菜单。
`wl_image_settings_overlay`为1级流水线，小LUT字形，不增加字体BRAM。
面板范围x140～499、y144～319，不遮底部站点字幕和路线条。
