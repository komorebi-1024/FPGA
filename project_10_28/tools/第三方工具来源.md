# 第三方工具来源

Icarus Verilog 是开源仿真器。本机使用 v12 development Windows 发行包，下载地址为 https://bleyer.org/icarus/iverilog-v12-20220611-x64_setup.exe ，安装到本目录的 iverilog 文件夹。原安装器保留在 _history 中。

上游项目与源代码：https://github.com/steveicarus/iverilog 。安装包中附带的 GTKWave 是波形查看器，项目主页：https://gtkwave.sourceforge.net/ 。本项目没有改动这些工具的二进制。

Tang Dynasty 使用用户已安装的软件，没有将 TD 本体或许可复制到交接 ZIP。代码中的安路 IP 保留原始版权与加密内容。

音频素材准备使用 imageio-ffmpeg 0.7.0（从官方 PyPI https://pypi.org/project/imageio-ffmpeg/ 下载），
安装在 `tools/audio_deps/`，仅用于电脑端 MP3→WAV 转换，不运行于 FPGA。
项目与源码：https://github.com/imageio/imageio-ffmpeg 。Python 包采用 BSD-2-Clause，
其随附 FFmpeg 可执行文件的具体构建选项与许可见 `ffmpeg -version` 以及包内附带文件；
未经修改。FFmpeg 源码与许可：https://ffmpeg.org/legal.html 。

## 站点合成语音

本次实际使用 **edge-tts 7.3.1**，安装在 `tools/audio_deps/`。
这是访问 Microsoft Edge 在线文本转语音服务的第三方 Python 客户端，项目与源代码：
https://github.com/rany2/edge-tts ，包页面：https://pypi.org/project/edge-tts/7.3.1/ 。
客户端代码许可为 LGPLv3，随安装包保留其 LICENSE；该代码许可不等同于语音服务或输出音频的许可。

当前四站播报由该在线服务的普通话女声 **`zh-CN-XiaoxiaoNeural`** 合成，
不是现场真人录音或声音克隆。文本为本工程的站名、景点介绍和下车提醒，见
`01_Assets/Voice/script.json`；激活音色、实际引擎速率、分段样本边界及文件哈希以
`01_Assets/Voice/narration.json` 为准。

联网仅发生在电脑端请求合成语音时，之后由本机 FFmpeg 转为48kHz/16位/双声道PCM WAV、
按实际样本数校准并打包入SD镜像。生成字幕字模、打包已有WAV、仿真以及FPGA板上播放均不需要
连接合成服务；开发板只读取本地SD卡，没有在线配音依赖。

初次神经语音试听由 `tools/prepare_neural_narration.py` 生成；
用户确认的校准试听由 `tools/calibrate_neural_narration.py` 生成，来源分段MP3/WAV保存在
`01_Assets/Voice/NeuralMatched/Sources/`，当前主WAV从该确认版本选用。
相对最初Huihui试听，最终总样本数约为原来的1/1.2；实际Edge引擎参数分别是
−13%、−11%、−11%、−14%，再作小于1%的时长微调，不能误写为直接使用引擎 `+20%`。
