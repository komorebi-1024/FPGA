## 行为

- 复位后首站图片提交先等待5秒，让HDMI接收设备完成锁定，再响约1秒提示音、播放本站介绍；后续到站不加5秒等待。
- 字幕按三段切换，每段依据实际播出的样本进度逐字出现；不是逐音素/逐字强制对齐。
- 播报结束后保留最后一句及站点画面3秒，再自动离站；KEY2可随时提前离站。
- 板上KEY2可随时打断语音离站，背景音乐从原位置续播。
- KEY1仍为复位，KEY3仍为切歌，SW1频谱，SW2测试音（正常播报时关闭）。

## 来源与复现

原试听在 `LegacyHuihui/`，初版神经配音在 `Neural/`，用户确认的校准版本在 `NeuralMatched/`。
当前主目录的四个WAV与`narration.json`已选用确认后的`NeuralMatched`版本。
初版生成脚本为`tools/prepare_neural_narration.py`；校准脚本为`tools/calibrate_neural_narration.py`。
它们仅供制作/试听，不由打包按钮自动调用，输出位于各自试听目录，不会自行激活或下载到板卡。
校准脚本会拒绝覆盖已存在的目标WAV；初版生成脚本可能重新生成其`Neural/`目录中的合并WAV，
再次制作前应先保存已经确认的试听版本。

校准依据是**原Huihui样本数**，不是把两个引擎的速率百分比直接相加。
当前四站实际Edge速率为−13%、−11%、−11%、−14%，再用小于1%的微调得到相对原试听快20%的精确总时长。
重新制作时应保留原Huihui参考及脚本要求的源目录布局，不能拿已提速的主WAV再次当原始参考反复校准。
原始分段MP3/WAV与合成参数随各目录保留；语音样本均为48kHz/16bit/双声道PCM。

edge-tts工具、来源与联网范围说明见`tools/第三方工具来源.md`。板上播放完全使用SD本地资源；
当前用户SRAM实机验收、Flash读回校验和完全断电冷启动均通过；长时运行及整曲曲尾实机循环仍待验收。
