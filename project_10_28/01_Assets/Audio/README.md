# 音乐素材放置处

将音乐以 **PCM WAV、48000 Hz、16 位、双声道** 格式导出到本目录：

```
music01.wav
music02.wav
music03.wav
music04.wav
```

至少一首即可，最多四首。编号必须从 01 开始连续，例如两首为 01、02。
不能将 MP3 改扩展名充当 WAV；浮点 WAV、压缩 WAV、44.1 kHz、24 位也需先转换。
当前已包含两首演示音乐：music01.wav 为舒缓钢琴，music02.wav 为轻快器乐。
来源、作者及 CC BY 4.0 署名要求见 `音乐来源与许可.md`；可以自行替换。
空目录会生成无音乐的静音镜像。

回到工程根目录，双击 `04_Pack_Audio.cmd`。
成功后将 `01_Assets/WestLake_TF_Audio_128MiB.img` 整盘写入专用 TF 卡。
写卡会覆盖原卡内容，先备份需要保留的资料；不要手工复制或替换卡内文件。

音乐与图片共享固定的 128 MiB 镜像容量，总音频时长约可容纳 9 分钟，
以打包工具的空间校验为准。加减音乐只需重新打包并写卡，无需重新综合 FPGA。

第一版菜单显示 `MUSIC 1/4` 等曲目编号，不显示文件名或中文曲名。
板上 KEY1：复位（RTL `rst_n`）。
板上 KEY2：模拟进站/离站（RTL `key1`，不要按板上 KEY1）。
板上 KEY3：下一首，从新曲开头播放并显示约 3 秒菜单（RTL `key_audio`）。
到站暂停音乐，离站继续；曲尾循环当前歌曲。
SW1：高电平时启用区间频谱，低电平关闭；实际拨杆方向以板上电平为准。
SW2：高电平启用不依赖 SD 卡的持续测试音，菜单显示 TEST TONE 440 HZ。
正常音乐播放请关闭 SW2；否则测试音优先并暂停音乐取样。
